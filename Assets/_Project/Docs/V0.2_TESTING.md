# V0.2 Testing

## Editor

1. Create/open a Unity project.
2. Add the `MiniGameCollection` script to a Canvas GameObject.
3. Enter Play mode.
4. Select each of the ten games from the hub.
5. Verify score, timer, completion, Retry and Home.

## Mobile

Test in portrait mode with touch input. Confirm buttons remain reachable on common phone aspect ratios and that the 30-second timer remains responsive.

## Acceptance criteria

- All ten games launch from the hub.
- No external asset/package is required for the prototype.
- Every game has a repeatable interaction loop.
- Every game exits cleanly through Retry or Home.
- No generated Unity Library/Temp/Build files are committed.
