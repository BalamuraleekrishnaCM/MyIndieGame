# V0.2 Gameplay Prototype

## Goal
Turn the ten-game hub from a UI mock into a lightweight playable mechanics prototype.

## Shared rules
- Each session lasts 30 seconds unless the game is completed earlier.
- Every game has a score.
- Every game has Retry and Home navigation.
- The prototype uses runtime-generated Unity UI and primitive/text representations.
- No art, audio, monetization, analytics, or external SDK is required yet.

## Game mechanics

### 1. Tap Rush
Tap the target repeatedly. The target relocates after every successful tap. Reach 20 taps for an early completion.

### 2. Color Match
A target color is displayed. Selecting the matching button awards points; incorrect choices lose a point.

### 3. Stack It
A moving block must be stopped near the center. Accuracy determines the points earned.

### 4. Dodge Line
Move between three lanes. Each move generates a new obstacle lane; selecting a safe lane scores points.

### 5. Coin Catch
Choose the coin action for points or dodge the hazard action for a smaller safe score.

### 6. Memory Flip
Eight cards represent four pairs. Selecting cards tracks matching attempts and awards points for matches.

### 7. One Tap Jump
Tap at each obstacle encounter. A lightweight timing roll determines whether the jump succeeds in the prototype.

### 8. Ball Sort
Perform sorting moves until the target score is reached.

### 9. Parking Puzzle
Move vehicles through the route. Five successful moves complete the prototype puzzle.

### 10. Merge 2048
Merge equal adjacent values. The prototype demonstrates the merge loop and score accumulation.

## Next pass
