# V0.2 Implementation Notes

The ten games are implemented behind one lightweight `MiniGameCollection` controller so the prototype can be tested without imported art or third-party packages.

The controller creates its Canvas UI at runtime and provides the hub, game selection, 30-second sessions, score updates, completion states, Retry and Home navigation.

This is intentionally a mechanics prototype rather than the final architecture. V0.3 should split each game into its own component/scene while retaining shared session and result services.
