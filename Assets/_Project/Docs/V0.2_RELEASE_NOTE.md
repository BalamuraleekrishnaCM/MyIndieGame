# V0.2 Release Note

## Playable Casual Collection

V0.2 upgrades the first prototype from a static game list into an interactive ten-game collection.

### Included
- Tap Rush
- Color Match
- Stack It
- Dodge Line
- Coin Catch
- Memory Flip
- One Tap Jump
- Ball Sort
- Parking Puzzle
- Merge 2048

### Shared prototype features
- Game hub
- 30-second sessions
- Score updates
- Completion states
- Retry
- Home navigation

### Known prototype limitations
- Placeholder visuals
- No final audio/haptics
- Some mechanics are intentionally lightweight/randomized
- No persistent save system yet
- Requires Unity Editor/device playtesting
