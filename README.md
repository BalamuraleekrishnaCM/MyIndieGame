# MyIndieGame 🎮

A simple and addictive hyper-casual mobile game project made for fun, experimentation, and rapid gameplay iteration.

## 🎯 Project Goals

- Keep the core gameplay simple and fun
- Build a small, polished mobile game
- Experiment with gameplay mechanics and game feel
- Learn and iterate quickly

## 🛠️ Technology

- Unity
- C#
- Target platform: Mobile
- Genre: Hyper-casual / Arcade

## 🚧 Status

Early development — gameplay concept and prototype are being explored.

## 📌 Development Principles

1. Prototype first.
2. Keep the gameplay loop short and satisfying.
3. Avoid unnecessary complexity.
4. Optimize for mobile performance.
5. Polish only after the core mechanic is fun.
